# 08_FaceEmo Splitter

FaceEmo の表情を、Prefab Variant のラベルごとに分けて適用します。

FaceEmo の「アバターに適用」は、Prefab Variant のいちばん親へ表情を書き込みます。
子の Variant で顔を改変して表情を作ると、親や兄弟にもその表情が入ります。
反対に、親で適用した表情が、顔を改変した子にも入ることがあります。
ラベルごとに表情を分けることで、それぞれの改変に合った表情を保てます。

## 必要なもの

FaceEmo 1.7.0 以降が必要です。2.x は未対応です。再生中・コンパイル中は使えません。

## 用語

| 用語 | 意味 |
|---|---|
| ラベル | 同じ表情を使う Variant のまとまり。A、B、C…と表示します |
| 起点 | ラベルが始まる Variant。表情はここに入り、配下が受け継ぎます |
| 担当 | ★で選ぶ、表情を作るために使う Variant。シーンに置き、FaceEmo のランチャーを用意します |

## 使い方

1. 表情を分けたい Variant をシーンに置き、FaceEmo でそれぞれの表情を作っておきます。ランチャーの対象をその Variant にしてください。
2. 「アバターの Prefab」に Prefab またはシーンのインスタンスを指定し、「読み込む」を押します。保存した設定ファイルがあれば、自動で読み込まれます。
3. 表情を分けたい Variant にラベルを付け、ラベルごとに★で担当を選びます。配下はラベルを受け継ぎます。
4. 作り直したいラベルの「適用する」を付け、「アバターに適用」を押します。確認ダイアログの内容を確認して適用してください。

系統には根から子孫までの Variant が並びます。名前をクリックすると Project ウィンドウで示されます。
ラベルは色の札で表示されます。塗りの札はその Variant で指定したラベル、枠だけの札は親から受け継いだラベルです。行もラベルの色で淡く塗られ、ラベルが始まる Variant（起点）は少し濃く、名前が太字になります。指定を変えた行には * が付きます。
担当の候補が 1 つなら自動で選ばれます。候補が複数ある場合は★で選んでください。
「適用する」を外したラベルは表情を作り直さず、今ある表情を使って配置します。

## 設定の保存

「保存」で、ラベル分け・担当（★）・「適用する」・Menu Installer のチェックを、Assets の中の設定ファイル（.json）に保存できます。
初めて保存するときに場所を選びます。設定ファイルが決まっていれば、適用が成功したあと自動で上書きされます。
「設定ファイル」欄から、読み込むファイルを選ぶこともできます。

Variant を改名・移動しても、アバターの配布元の Prefab を同じファイルのまま更新しても、設定は同じ Variant に付いたままです。
見つからない Variant があれば件数が表示されます。保存していない変更があると「保存」の横に * が付きます。

## MA Menu Installer の設定を維持する

FaceEmo を適用し直すと、メニューのインストール先などの設定が戻ってしまうことがあります。
「MA Menu Installer の設定を維持する」（既定 ON）を付けておくと、担当の Variant のシーンで設定したインストール先と有効・無効を引き継ぎます。
対象はインストール先と有効・無効だけです。

## 制限と注意

!!! warning "Prefab の書き換えは Undo で戻せません"
    確認ダイアログに書き換える Prefab が表示されます。事前にバージョン管理やバックアップで戻せる状態にしてください。
    書き換える Prefab が 0 件でも、「適用する」が付いたラベルの表情は作り直されます。

!!! warning "分けた Variant の表情オブジェクト名を変えないでください"
    表情オブジェクトは FaceEmoPrefab (Split) という名前になります。
    分けたあとに FaceEmo の「アバターに適用」を押しても構いませんが、シーンに FaceEmoPrefab が増えます。
    追加されたものを削除してから本ツールを使ってください。

- Prefab を変更した場合も読み込み直してください。
- サブアバターを設定したランチャーは使えません。
- ラベルを「継承」にして表情の無い親に揃えると、その Variant から表情が外れます。
- 書き換えられるのは Assets/ の中の Prefab です。Packages/ の Prefab とモデルは対象外です。

## よくある症状

| 症状 | 対処 |
|---|---|
| ★が出ない | その Variant をシーンに置き、FaceEmo のランチャーの対象にしてから読み込み直してください |
| 「シーンに追加された FaceEmoPrefab があります」と出る | FaceEmo の「アバターに適用」で増えたものです。シーンの Variant の中の FaceEmoPrefab を削除してください |
| 「まだ表情が作られていません」と出る | 新しく作ったラベルです。担当を選び、「適用する」を付けてください |
| 適用するとメニューのインストール先が戻る | 「MA Menu Installer の設定を維持する」を付け、担当の Variant のシーンでインストール先を設定してから適用してください |
