# 07_Parts Set Adjuster

0.8 までは `07_Hair Set Adjuster` という名前でした。有効にしていれば、そのまま使えます。

別のアバター向けの髪・帽子・眼鏡・しっぽ・羽・腕輪などを、体に合わせて取り付けるのを手伝います。
アバターの軸に沿ったスライダーで位置・角度・大きさを整え、顔の形を見て位置と大きさを自動で合わせられます。

## 必要なもの

VRChat SDK - Base 3.5.0 以降が必要です。再生中は使えません。

## 入力

| 入力 | 選び方 |
|---|---|
| 種類 | 「髪」か「髪以外」。自動で合わせるは髪のときだけ使えます |
| 基準のメッシュ | 髪なら顔、しっぽなら体など、合わせたい肌のメッシュ |
| 基準の部位 | 頭・腰・左手など 20 か所。髪のときは頭に固定されます |
| パーツ | アバターの中に置いた、取り付けたいパーツ |
| 動かす範囲 | パーツ全体、指定したボーン、指定したメッシュから選べます |

## 動かす範囲

「パーツ全体」は、パーツの中の基準部位のボーンを自動で選びます。無ければパーツのルートを選びます。
「ボーンを指定」は、そのボーンと配下を動かします。衣装の中の帽子だけを動かすときは、こちらで帽子のボーンを選んでください。
「メッシュを指定」は、そのメッシュを動かしているボーンを自動で選びます。

ほかのメッシュと同じボーンで動くメッシュは、それだけを動かせません。
何が一緒に動くかは入力欄の下に表示されます。範囲を指定したときは、めり込みチェックと自動で合わせるも動く頂点だけで測ります。

## 使い方

1. 新しいパーツをアバターの中に置きます。髪を交換する場合は元の髪を外しておきます。
2. 種類・基準のメッシュ・基準の部位・パーツを指定し、動かす範囲を選びます。
3. 「肌の色を変える」を ON にして、パーツと肌の境目を見やすくします。
4. 髪のときは「自動で合わせる」を押します。顔の形を見て、位置と大きさが合わせられます。
5. スライダーで位置・角度・大きさを整えます。髪以外はここで合わせてください。めり込みの表示も確認します。
6. パーツに PhysBone Collider があれば、「Collider を確認」→「移行」で本体のものへ移せます。

調整・自動で合わせる・移行はすべて「元に戻す（Undo）」で取り消せます。
エディタ上で動かした位置は、アップロード時の統合（Modular Avatar など）でもそのまま使われます。

## 位置合わせ

「左右」「上下」「前後」は、アバタールートの軸で移動します。
角度と大きさは基準の部位の中心まわりで変わります。「軸ごとの大きさ」は調整の対象のローカル軸ごとの倍率です。

スライダーは、いまの値を中心に動かせます。端までドラッグして離すと、その値が新しい中心になり、さらに先へ動かせます。
右の数値欄には、スライダーの幅を超える値も直接入れられます。
「スライダーの幅」で「大きく」「ふつう」「細かく」を選べます。細かい調整には「細かく」を使ってください。

「自動で合わせる」は、髪の中の頭ボーンをアバターの頭ボーンに合わせた位置から始めます。
頭の上半分へのめり込み・外から見える地肌・頭から浮いた部分が減るように、位置と大きさを調整します。
すでに合っている髪は、ほとんど動きません。
頭ボーンが無い髪にも使えますが、手がかりが少ないため、合わせたあとで後頭部やうなじが出ていないか確かめてください。
動かすのは位置と均等な大きさだけで、角度と軸ごとの大きさは変えません。自動で合わせるは種類が髪のときだけ使えます。

位置だけを合わせたいときは、「大きさも合わせる」を切ってください。
大きさはスライダーで整えられます。

「基準をいまの姿勢にする」は、現在の姿勢をスライダーの基準にします。「基準に戻す」はその姿勢へ戻します。
アバター自体を動かしたあとは、基準を取り直してください。

## 肌の色を変える

基準のメッシュをマゼンタ・シアン・黄の単色で表示し、地肌のはみ出しとパーツの貫通を見やすくします。
手前のパーツはそのまま見えます。Scene ビューにだけ表示し、Game ビューには出ません。

「パーツに隠れた部分も表示」（既定 ON）で、パーツの奥の肌が淡い同じ色で透けて見えます。
濃い色と淡い色の境目から、地肌がパーツを突き抜けている場所を確認できます。

!!! info "肌の色は一時的な表示です"
    ウィンドウを閉じると元の表示へ戻ります。シーンやマテリアルは変更していません。

## めり込みチェック

「チェック」で、基準の部位の表面より内側にあるパーツの頂点数と、測った全頂点数を表示します。
範囲を指定している場合は、動く頂点だけが対象です。表面から深く離れた頂点は数えないため、完全に埋まったパーツも目で確認してください。
「めり込んだ位置を表示」が ON なら、その位置を Scene ビューに示します。
「表し方」で「面」（既定）・「点」・「面と点」を選べます。
面は、めり込んだ頂点を含むパーツの面を半透明の赤で塗り、体の中に埋まっていても見えます。点は最大 2,000 点です。
自動で合わせたあとと、スライダーを動かし終えたあとに数が更新されます。
確認後に別の操作で動かした場合は、もう一度チェックしてください。

## Collider の移行

パーツの PhysBone が参照するパーツ側の Collider を、本体側の同等な Collider へ付け替えます。
「Collider を確認」で候補を表示し、移す行にチェックを付けて「移行」を押します。
形・付いている骨・位置・大きさが近いものが候補になります。平面は対象外です。
本体側の Collider の値は変えません。

!!! warning "位置合わせのあとに確認してください"
    位置が合っていないと、同じ役目の Collider でも候補に出ません。位置を動かしたら再確認してください。
    Collider の削除は「使われなくなったパーツ側の Collider を削除する」を選んだときだけ行います。既定では削除しません。
    選んだ場合も、アバター全体の PhysBone から使われていないコンポーネントだけを削除し、ボーンや GameObject は残します。

## 制限と注意

髪以外は自動で合わせられません。スライダーで調整してください。
同じボーンで動いているメッシュを分離したり、メッシュの形を編集したりすることはできません。
基準の部位に対応するボーンがアバターに無い場合は、近い部位を選んでください。

## よくある症状

| 症状 | 対処 |
|---|---|
| 自動で合わせた大きさが好みと違う | 「大きさも合わせる」を切ってから押し直し、大きさはスライダーで整えてください |
| 「自動で合わせる」が押せない | 種類が「髪以外」になっています。髪以外はスライダーで合わせてください |
| 帽子だけを動かしたいのに、ほかの飾りも動く | 同じボーンで動いています。それだけを動かすことはできません。「一緒に動くメッシュ」を確かめてください |
| 基準の部位を選ぶと「ボーンがありません」と出る | そのアバターはその部位のボーンを持っていません。上胸・首・肩は省略されることがあります。近い部位を選んでください |
| スライダーで思った値まで動かせない | 端まで動かして離すと、そこが新しい中心になります。数値欄に直接入れることもできます |
| スライダーが動かせない | アバターを動かしたあとは、「基準をいまの姿勢にする」を押してください |
| Collider の候補が出ない | 位置を合わせてから確認してください。形や大きさが大きく違う Collider は候補になりません |
| 肌の色が変わらない | Scene ビューにだけ表示されます。Game ビューには出ません |
