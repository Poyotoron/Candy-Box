# 07_Hair Set Adjuster

別のアバター向けに作られた髪を、頭に合わせて取り付けるのを手伝います。
頭の軸に沿ったスライダーで位置・角度・大きさを整え、頭に沿ってめり込みが少ない位置を探せます。

## 必要なもの

VRChat SDK - Base 3.5.0 以降が必要です。再生中は使えません。

## 使い方

1. 新しい髪をアバターの中に置きます。元の髪は外しておきます。
2. 顔メッシュと髪を指定します。調整の対象は自動で選ばれます。
3. 「顔の色を変える」を ON にして、髪と顔の境目を見やすくします。
4. 「頭ボーンに合わせる」を押します。多くの髪はこれでほぼ正しい高さに来ます。
5. 「めり込みが少ない位置を探す」で位置を詰めます。
6. スライダーで角度と大きさを整えます。めり込みの数を見ながら調整してください。
7. 髪に PhysBone Collider があれば、「Collider を確認」→「移行」で本体のものへ移せます。

調整・探索・移行はすべて「元に戻す（Undo）」で取り消せます。
エディタ上で動かした位置は、アップロード時の統合（Modular Avatar など）でもそのまま使われます。

## 位置合わせ

「左右」「上下」「前後」は、頭の向きに沿ったアバタールートの軸で移動します。
角度と大きさは頭の中心まわりで変わります。「軸ごとの大きさ」は調整の対象のローカル軸ごとの倍率です。

「頭ボーンに合わせる」は、髪の頭ボーンをアバターの頭ボーンの位置へ合わせます。
髪の頭ボーンが見つからなければ髪のルートが調整の対象になります。必要なら対象を髪の中から直接指定できます。

「基準をいまの姿勢にする」は、現在の姿勢をスライダーの基準にします。「基準に戻す」はその姿勢へ戻します。
アバター自体を動かしたあとは、基準を取り直してください。

「めり込みが少ない位置を探す」は、現在の近くで頭に沿っていてめり込みが少ない位置を探します。
頭への近さも評価するため、髪を浮かせてめり込みを消す位置は選びません。
動かすのは位置（上下・前後）だけです。角度と大きさはスライダーで調整してください。

## 顔の色を変える

顔をマゼンタ・シアン・黄の単色で表示し、地肌のはみ出しと髪の貫通を見やすくします。
手前の髪はそのまま見えます。Scene ビューにだけ表示し、Game ビューには出ません。

!!! info "顔の色は一時的な表示です"
    ウィンドウを閉じると元の表示へ戻ります。シーンやマテリアルは変更していません。

## めり込みチェック

「チェック」で、頭の表面より内側にある髪の頂点数と、髪の全頂点数を表示します。髪飾りも含みます。
「めり込んだ位置を表示」が ON なら、その位置を Scene ビューに赤い点で示します（最大 2,000 点）。
スライダーを動かし終えると自動で数が更新されます。確認後に別の操作で動かした場合は、もう一度チェックしてください。

## Collider の移行

髪の PhysBone が参照する髪側の Collider を、本体側の同等な Collider へ付け替えます。
「Collider を確認」で候補を表示し、移す行にチェックを付けて「移行」を押します。
形・付いている骨・位置・大きさが近いものが候補になります。平面は対象外です。
本体側の Collider の値は変えません。

!!! warning "位置合わせのあとに確認してください"
    位置が合っていないと、同じ役目の Collider でも候補に出ません。位置を動かしたら再確認してください。
    Collider の削除は「使われなくなった髪側の Collider を削除する」を選んだときだけ行います。既定では削除しません。
    選んだ場合も、アバター全体の PhysBone から使われていないコンポーネントだけを削除し、ボーンや GameObject は残します。

## よくある症状

| 症状 | 対処 |
|---|---|
| 「頭ボーンに合わせる」が押せない | 髪の中に、アバターの頭ボーンと同じ名前のボーンが無いか、調整の対象が髪の頭ボーンより下にあります。調整の対象を空欄に戻すか、髪の頭ボーンかその親を選んでください |
| スライダーが動かせない | アバターを動かしたあとは、「基準をいまの姿勢にする」を押してください |
| Collider の候補が出ない | 位置を合わせてから確認してください。形や大きさが大きく違う Collider は候補になりません |
| 顔の色が変わらない | Scene ビューにだけ表示されます。Game ビューには出ません |
