# 05_Bone Weight Collapser

不要なボーンのウェイトを、別のボーンへ寄せます。

必要な追加パッケージはありません。

## こんなときに使います

- 袖が指ボーンにウェイトを持っているため、ハンドサインで袖が変形してしまう
- スカートの補助ボーンや顔の追従ボーンの影響を切りたい
- Blender へ持ち出さずに Unity 上で直したい

## 使い方

1. 対象オブジェクトを指定し、「メッシュを収集」で配下のメッシュを一覧にします。
2. 処理するメッシュにチェックを付けます。既定ではどれも選ばれていません。
3. 移動元ボーンを「直接指定」か「子孫」で指定します。
4. 移動先ボーンを指定します。
5. 「影響を確認」で、影響する頂点数と移動するウェイト量を確認します。
6. 出力フォルダを指定し、「適用」を押します。

!!! info "静止時の見た目は変わりません"
    ボーンウェイトを移し替えても、静止時の見た目は変わりません。
    動いたときの追従先だけが変わります。

    頂点の位置・法線・シェイプキーには一切手を加えません。

### 移動比率

移動比率は、移動元のウェイトをどれだけ移動先へ渡すかを指定します。

| 値 | 動作 |
|---|---|
| `1.0` | 移動元のウェイトを完全に移します |
| `0.5` | 半分だけ移し、移動元への追従も部分的に残します |

## 出力について

新しいメッシュを `.asset` として出力し、対象のメッシュ参照を差し替えます。
元のメッシュや FBX は変更しません。

同名のファイルがある場合は連番を付け、既存のファイルを上書きしません。
同じメッシュを共有し、ボーンの並びも同じ対象は、1 つの出力にまとめられます。

## 制限と注意

!!! warning "移動先には、メッシュが使用しているボーンを指定してください"
    移動先ボーンは、そのメッシュがもともとウェイトを持っているボーンから選びます。
    メッシュのボーン一覧に無いボーンは移動先にできません。

- ボーン自体は削除しません。ボーンを減らしたい場合は別の手段を使ってください。
- 再生中は実行できません。
- 適用は「元に戻す（Undo）」で取り消せますが、生成したメッシュのファイルは残ります。

## よくある症状

| 症状 | 対処 |
|---|---|
| 移動先ボーンを指定しても対象がチェックできない | そのメッシュのボーン一覧に移動先ボーンが含まれていません。メッシュがウェイトを持っている別のボーンを選んでください |
| 「影響を受ける頂点がありません」と出る | 指定した移動元ボーンに、そのメッシュのウェイトが乗っていません。移動元の指定を見直してください |
| 適用しても見た目が変わらない | 静止時の見た目は変わりません。アニメーションを再生して追従を確認してください |
| 生成したメッシュが増えていく | 同名を上書きしないため、適用のたびに新しいファイルが作られます。不要なものは手動で削除してください |
