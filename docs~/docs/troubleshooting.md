# 困ったときは

## 設定ウィンドウまわり

??? question "`Tools > Candy Box` がメニューに無い"
    パッケージが導入できていません。[インストール](install.md)を確認してください。
    VCC から追加した場合は、Unity 側でプロジェクトを開き直すと反映されます。

??? question "ツールのメニュー項目が増えない"
    ツールごとのメニュー項目はありません。`Tools > Candy Box` は 1 項目だけで、
    各ツールは設定ウィンドウの「開く」から起動します。

??? question "チェックを入れたのにツールが開けない"
    「適用」を押していない可能性があります。
    チェックは保留状態で、「適用」を押して再コンパイルが終わるまで有効になりません。
    詳しくは[設定ウィンドウ](settings.md)を参照してください。

??? question "「必要なパッケージがありません」と出る"
    そのツールが連携するパッケージが未導入です。
    詳細欄に必要なパッケージと必要バージョンが表示されるので、それを導入してください。

??? question "有効にしたはずのツールが無効に戻っている"
    連携先のパッケージを削除すると、そのツールはコンパイル対象から外れます。
    設定自体は残っているため、パッケージを戻せばまた使えます。

??? question "プラットフォームを切り替えたら使えなくなった"
    有効・無効の設定は PC / Android / iOS の 3 つすべてに書き込まれます。
    それでも外れている場合は、設定ウィンドウでチェックを入れ直して「適用」してください。

## 実行できないとき

どのツールも、**再生中（Play Mode）は実行できません。**
再生中はシーンへの変更が保存されず、値も実行時のものに書き換わっているためです。

00_Blendshape Keeper は、**Animation ウィンドウのプレビュー中**も実行できません。
プレビュー中は、メッシュの表示値がクリップ由来の値になっているためです。

ボタンが押せないときは、その近くに理由が表示されます。

## 変更を取り消したい

適用した変更は、原則として**「元に戻す（Undo）」**（Ctrl+Z）で取り消せます。

!!! warning "戻せないものがあります"
    | 操作 | 戻せるか |
    |---|---|
    | シーン・マテリアルの値の変更 | 戻せます |
    | `Renderer` のマテリアル参照の差し替え | 戻せます |
    | **新しく生成したファイル**（複製マテリアル、テクスチャ、LUT、マスク、複製アニメーション） | **残ります。** 不要なら手で削除してください |
    | **テクスチャの焼き直し** | **戻せません**（ファイルの更新のため） |

    また、Unity の再起動やスクリプトの再コンパイルをまたぐと、Undo の履歴は失われます。

## ファイルが増えてしまった

複製を作るモードでは、同名のファイルがあると**連番付きの別名**で保存します。
既存のファイルを壊さないことを優先しているため、繰り返し実行するとファイルが増えます。

不要なものは Project ウィンドウから削除してください。
**同じファイルを更新し続けたい場合は、上書きモード**（対応しているツール）を使います。

## 05_Bone Weight Collapser の結果について

??? question "適用しても静止時の見た目が変わらない"
    正常です。ボーンウェイトの移動では、静止時の頂点位置は変わりません。
    アニメーションを再生し、移動元ではなく移動先のボーンへ追従することを確認してください。

??? question "元に戻したのに生成したメッシュが残っている"
    「元に戻す」や Undo が戻すのは、`SkinnedMeshRenderer` のメッシュ参照です。
    出力されたメッシュのファイルは削除されないため、不要になったものは Project ウィンドウから手動で削除してください。

## 元のファイルを壊したくない

各ツールとも、元のファイルに書き込まない方法を用意しています。

| ツール | 元を変更しない方法 |
|---|---|
| 00_Blendshape Keeper | 「別のアニメーションとして保存」 |
| 04_Hair Tone Matcher | 「複製 + テクスチャ焼き込み」または「複製して差し替え」 |
| 05_Bone Weight Collapser | 常に新しいメッシュを出力し、元のメッシュは変更しません |

01 / 02 / 03 は、シーン上のコンポーネントの設定を変更するツールです。
適用前に対象と内容を一覧で確認できます。

## それでも解決しないとき

再現手順を添えて、[GitHub の Issue](https://github.com/Poyotoron/Candy-Box/issues) へお知らせください。
次の情報があると調査が進みます。

- Unity のバージョン
- Candy Box のバージョン（このページのフッタに、ドキュメントが対応するバージョンを表示しています）
- 連携先パッケージのバージョン（該当するツールの場合）
- ウィンドウに表示されたメッセージ
